# Snow 产品视觉规范

本文件与 SnowEdge 的 `design/SNOW_DESIGN_SYSTEM.md` 同步。SnowEdge、SnowRelay 与 SnowLens 统一使用浅色雪山工作台视觉语言。

## 核心变量

| 语义 | 色值 |
| --- | --- |
| 主色 | `#4F46E5` |
| 主色悬停 | `#4338CA` |
| 主色浅底 | `#EEF2FF` |
| 联动与成功 | `#14B88A` |
| 页面背景 | `#F6F8FC` |
| 卡片背景 | `#FFFFFF` |
| 次级背景 | `#F8FAFD` |
| 主文字 | `#17213A` |
| 次文字 | `#64748B` |
| 边框 | `#DCE3EE` |
| 高危/错误 | `#BE123C` |
| 中危/警告 | `#B45309` |
| 低危 | `#8A6D1D` |
| 信息 | `#0369A1` |

正文使用 11 pt，辅助文字 10 pt，页面标题 18–20 pt。按钮最小高度约 40 px，输入框约 42 px，侧栏宽 220 px，品牌图标 36 px。代码区使用浅灰蓝背景与细边框，禁止纯黑提示框。

三款工具统一提供 90%、100%、110%、120%、130% 五档显示大小并记住选择。风险色只表达风险；薄荷绿用于成功、联动和已验证状态。
